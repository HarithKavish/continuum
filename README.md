# Continuum

Continuum is a browser-native spatial exploration environment: an interactive 3D Earth
built from real, publicly accessible data — terrain, satellite imagery, bathymetry and
natural events — with no backend, no accounts and no API keys.

- **Live:** https://continuum.harithkavish.com
- **Ecosystem:** part of the HarithKavish ecosystem — see [GOVERNANCE.md](GOVERNANCE.md)
  and [AGENTS.md](AGENTS.md).

The application is being built on `development`; this branch holds the repository
scaffold.
